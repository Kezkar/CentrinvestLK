# CentrinvestLK

Интерактивный прототип личного кабинета партнёра ПАО КБ «Центр-инвест» для работы застройщиков с ипотечными заявками.

## Что реализовано

- роли сотрудника и руководителя партнёра;
- роли менеджера и администратора банка;
- сводная статистика и список заявок;
- карточка заявки, история статусов и решение банка;
- пошаговое создание ипотечной заявки;
- обмен документами между партнёром и банком;
- демонстрационный клиентский путь ЕСИА и предоставления согласий;
- управление сотрудниками, партнёрами и баннерами;
- демонстрация входа с двухфакторным подтверждением по SMS;
- адаптивный интерфейс.

## Важно

Проект является frontend-прототипом. CRM, ЕСИА, SMS, файловое хранилище и уведомления реализованы как демонстрационные сценарии без подключения к промышленным системам банка. Переключатель ролей предназначен только для демонстрации.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

После запуска откройте адрес, который выведет Vite.

Дополнительные команды:

```bash
npm run lint
npm run build
npm test
```

Скрипты сборки ориентированы на Linux и используют `bash`, GNU `timeout`, `flock` и `curl`.

## Основные файлы

- `app/page.tsx` — экраны, роли и интерактивные сценарии;
- `app/globals.css` — фирменные стили и адаптивность;
- `app/layout.tsx` — метаданные приложения;
- `public/centrinvest-logo.svg` — логотип банка;
- `package.json` — зависимости и команды.

## Перед промышленной эксплуатацией

Необходимо заменить демонстрационные данные на backend API банка, убрать ручное переключение ролей, подключить корпоративную аутентификацию, CRM, ЕСИА, SMS-шлюз, файловое хранилище и журналирование операций. Также требуется пройти проверки информационной безопасности и нагрузочное тестирование.
